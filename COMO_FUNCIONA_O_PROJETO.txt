RESUMO DO PROJETO
================================================================================
Este é um sistema de análise financeira que coleta dados da B3 (Bolsa de 
Valores brasileira), armazena em um banco PostgreSQL e gera relatórios e 
gráficos interativos sobre ações, FIIs e dividendos.

OBJETIVO PRINCIPAL
================================================================================
- Automatizar a coleta de dados financeiros da B3
- Organizar dados em um banco de dados estruturado  
- Gerar relatórios e análises visuais
- Criar dashboards interativos para tomada de decisão

ESTRUTURA DO BANCO DE DADOS
================================================================================
O sistema usa 3 tabelas principais:

1. ATIVOS - Lista de todos os ativos (ações, FIIs, ETFs, BDRs)
   - Código (PETR4, VALE3, etc.)
   - Nome da empresa
   - Tipo (ACAO, FII, ETF, BDR)
   - Setor (Petróleo, Bancos, etc.)

2. COTAÇÕES - Preços históricos diários
   - Preço abertura, fechamento, máximo, mínimo
   - Volume financeiro negociado
   - Data da cotação

3. DIVIDENDOS - Histórico de dividendos pagos
   - Valor do dividendo
   - Data de pagamento
   - Tipo de provento

FUNCIONALIDADES DETALHADAS
================================================================================

1. COLETAR DADOS B3 (D-1)
----------------------------
O QUE FAZ:
- Baixa arquivo COTAHIST da B3 (dados do dia anterior)
- Extrai informações de ~500 ativos
- Classifica por tipo (Ação, FII, ETF, BDR) e setor
- Salva cotações históricas
- Processa dividendos

QUANDO USAR:
- Na primeira execução (obrigatório)
- Diariamente para manter dados atualizados
- Após fim de semana ou feriados

RESULTADO:
- Tabela "ativos" populada com ~500 ativos
- Tabela "cotacoes" com preços do dia anterior
- Tabela "dividendos" com proventos recentes

2. CONSULTAR ATIVOS
---------------------
O QUE FAZ:
- Lista todos os ativos disponíveis
- Filtra por tipo (Ação, FII, ETF, BDR)
- Filtra por setor (Bancos, Petróleo, etc.)

COMO USAR:
1. Clique em "Consultar Ativos"
2. Escolha filtros (ou deixe vazio para ver todos)
3. Veja a lista completa em uma janela

RESULTADO:
- Tabela com código, nome, tipo e setor
- Informações organizadas e filtradas

3. HISTORICO DE COTACOES
--------------------------
O QUE FAZ:
- Mostra preços históricos de um ativo específico
- Gera gráfico de candlestick interativo PROFISSIONAL
- Inclui volume de negociação
- Calcula linhas de suporte e resistência
- Abre automaticamente no navegador

COMO USAR:
1. Clique em "Histórico de Cotações"
2. Digite código do ativo (ex: PETR4)
3. Escolha período em dias (ex: 30)
4. Clique em "Buscar Historico" ou "Gerar Grafico"

RESULTADO:
- Tabela com preços diários (OHLC + Volume)
- Arquivo HTML com gráfico interativo estilo TradingView
- Cores profissionais (verde/vermelho)
- Linhas de suporte e resistência automáticas
- Análise visual completa de tendências

4. RELATORIO DE DIVIDENDOS
----------------------------
O QUE FAZ:
- Lista dividendos pagos por ativos
- Filtra por ativo, ano e trimestre
- Gera gráfico de distribuição mensal

COMO USAR:
1. Clique em "Relatório de Dividendos"
2. Escolha ativo (opcional)
3. Escolha ano e trimestre
4. Marque se quer gráfico

RESULTADO:
- Lista de dividendos pagos
- Gráfico de barras por mês
- Análise de yield e frequência

5. DADOS HISTORICOS (30d)
---------------------------
O QUE FAZ:
- Gera dados históricos simulados para os últimos 30 dias
- Cria cotações baseadas nos preços atuais com variações realistas
- Permite gráficos com mais dados históricos
- Pula fins de semana automaticamente

QUANDO USAR:
- Quando não há dados históricos suficientes
- Para testar gráficos de candlestick
- Para análises de tendências de longo prazo

COMO USAR:
1. Clique em "Dados Historicos (30d)"
2. Confirme a geração de dados simulados
3. Aguarde o processamento (pode demorar alguns minutos)

RESULTADO:
- 30 dias de cotações históricas simuladas
- Dados realistas baseados em preços atuais
- Gráficos de candlestick mais completos

6. RESUMO DO SISTEMA
----------------------
O QUE FAZ:
- Mostra estatísticas gerais do banco
- Conta registros em cada tabela
- Verifica integridade dos dados

RESULTADO:
- Total de ativos cadastrados
- Total de cotações armazenadas
- Total de dividendos registrados

7. EXECUTAR TODOS OS RELATORIOS
---------------------------------
O QUE FAZ:
- Executa todos os relatórios de uma vez
- Gera todos os gráficos disponíveis

QUANDO USAR:
- Para análise completa
- Apresentações
- Backup de relatórios

PROBLEMAS COMUNS E SOLUCOES
================================================================================

PROBLEMA: "Nenhum dado encontrado para [ATIVO]"
SOLUCAO: Execute "Dados Historicos (30d)" para gerar dados simulados

PROBLEMA: Gráfico de candlestick vazio ou com poucos dados
SOLUCAO: Use "Dados Historicos (30d)" para ter 30 dias de dados

PROBLEMA: "Nenhum ativo encontrado"
SOLUÇÃO: Execute "Coletar Dados B3" primeiro

PROBLEMA: Erro de conexão
SOLUÇÃO: Verifique se PostgreSQL está rodando (docker-compose up -d)

PROBLEMA: Relatório sem dados
SOLUÇÃO: Certifique-se que coletou dados da B3 recentemente

PROBLEMA: Código de ativo não encontrado
SOLUÇÃO: Use códigos corretos (PETR4, VALE3, ITUB4, etc.)
